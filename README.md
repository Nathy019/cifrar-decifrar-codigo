# 🔐 Cifra - Projeto Web

Este projeto é uma aplicação web simples desenvolvida em **PHP**, **HTML** e **CSS** com o objetivo de **cifrar e decifrar textos** utilizando o método da **Cifra** — uma técnica clássica de criptografia por substituição.

## 🧠 O que é a Cifra?

A Cifrar é uma técnica de criptografia onde cada letra do texto é substituída por outra letra deslocada um número fixo de posições no alfabeto. Por exemplo, com um deslocamento de 3:
A → D
B → E
C → F

---

## 💻 Funcionalidades

- ✍️ Formulário para digitar o texto a ser cifrado.
- 🔢 Definição do número de deslocamento (entre 3 e 25).
- 📜 Exibição do texto cifrado.
- 🔁 Página para decifrar o texto cifrado usando o mesmo deslocamento.
- 🎨 Estilização responsiva com CSS personalizado e Bootstrap.
- 🌙 Tema escuro com destaque visual e botões estilizados.
